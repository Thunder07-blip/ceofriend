Engineers think in:
- bugs
- commits
- failures  

CEOs think in:
- 💸 revenue loss  
- 📉 user churn  
- ⏳ downtime  
- ⚠️ business risk  

---

👉 This agent bridges that gap:


Technical Risk → Business Impact


---

## 🚀 Responsibilities

The Business Impact Agent must:

1. Take predicted risks from Prediction Agent  
2. Map each component to a business function  
3. Estimate:
   - revenue loss
   - downtime cost
   - user impact  
4. Calculate **expected loss**  
5. Provide clear explanations  

---

## ❗ What It DOES NOT DO

- ❌ No risk calculation  
- ❌ No prediction  
- ❌ No LLM generation  

👉 Only **business translation**

# ⚙️ Technical Implementation

---

## 🧩 Core Function

```ts
function calculateImpact(file) {
  const mapping = getBusinessMapping(file.file);

  const downtime =
    file.predictedRisk > 80
      ? 3
      : file.predictedRisk > 50
      ? 2
      : 1;

  const expectedLoss =
    file.failureProbability *
    mapping.impactPerHour *
    downtime;

  return {
    businessFunction: mapping.function,
    impactPerHour: mapping.impactPerHour,
    expectedDowntime: downtime,
    expectedLoss: Math.round(expectedLoss),
    userImpact: getUserImpact(mapping.function)
  };
}
``` id="impact-code"
